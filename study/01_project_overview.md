# 01. 프로젝트 개요

## NetHack이란?

NetHack은 던전 탐험형 로그라이크(roguelike) 게임입니다.

- **Rogue**(1980) → **Hack**(1984) → **NetHack**(1987~) 의 계보를 잇는 작품
- 텍스트(ASCII) 기반 인터페이스가 전통이지만, 현재는 타일 그래픽/마우스도 지원
- 수십 년에 걸쳐 수백 명의 개발자가 기여한, 가장 오래 유지보수되는 오픈소스
  게임 중 하나

## 버전 체계

현재 저장소의 코드는 **NetHack 5.0.1 작업중(work-in-progress)** 버전입니다.

- 5.0.0: 공식 릴리스
- 5.0.1: 주로 버그 수정. 아직 릴리스 전이며, 릴리스 후보가 아님
- 안정성이 최우선이라면 5.0.0 릴리스를 사용할 것을 권장 (README 참고)

버전 정보는 다음 파일들에서 관리됩니다:

| 파일 | 내용 |
|------|------|
| `include/patchlevel.h` | 패치레벨(버전) 정의 |
| `src/version.c` | `#version`, `--version` 출력 로직 |
| `DEVEL/VERSION` | 개발 버전 히스토리 |
| `doc/fixes5-0-1.txt` | 5.0.1에 반영된 수정 내역 |

## 5.0에서 달라진 점 (아키텍처 관점)

README에서 강조하는 5.0의 구조적 개선 사항은 다음과 같습니다.

### 1. C99 표준 준수

- 소스 코드가 C99 표준을 따름
- 함수 선언/정의가 ANSI 스타일로 통일됨 (`DEVEL/code_style.txt` 참고)

### 2. 크로스컴파일 지원

- 한 플랫폼에서 빌드하여 다른 플랫폼/OS에서 실행할 수 있도록 개선
- `make CROSS_TO_MSDOS=1`, `make CROSS_TO_WASM=1` 등으로 대상 지정
- 상세 내용은 최상위 `Cross-compiling` 파일과 `04_build_system.md` 참고

### 3. 빌드 시점 도구를 Lua로 대체

기존에는 다음 3가지가 빌드 시점에 `yacc`/`lex` 기반 도구로 처리되었습니다.

1. **레벨 컴파일러**(level compiler) — 특수 레벨(`.des` 파일) 처리
2. **던전 컴파일러**(dungeon compiler) — 던전 구조 처리
3. **퀘스트 텍스트 처리** — `makedefs`가 하던 퀘스트 텍스트 처리

이것들이 5.0에서 **게임 실행 중 로드되는 Lua 텍스트**로 대체되었습니다.
즉, 빌드 시점에 복잡한 파싱/컴파일을 하지 않고, 게임이 직접 `.lua` 파일을
읽어 처리합니다. 자세한 내용은 `05_lua_integration.md`에서 다룹니다.

## 지원 플랫폼

공식 릴리스(5.0) 기준으로 테스트된 환경 (README 발췌):

- Linux (x86), BSDI
- Windows 10/11
- macOS 10.11 ~ 26 (Intel, Apple Silicon)
- MS-DOS (djgpp 크로스컴파일)
- AmigaOS 3.0+

성공 사례가 있는 환경: OpenVMS (Alpha, Itanium, x86-64)

## 게임의 목표 (배경 지식)

코드를 이해하는 데 필요한 최소한의 게임 배경만 요약합니다.

- 플레이어는 직업(role)/종족(race)/성향(alignment)을 골라 던전에 입장
- 목표는 "Yendor의 아뮬렛"을 찾아 지옥(Gehennom)을 지나 제물로 바치는 것
- 턴 기반: 플레이어가 한 행동을 하면 몬스터가 반응
- 던전은 여러 **브랜치**(지부)로 구성: 미궁(Mazes of Menace), 소코반, 광산 등

이 배경 지식이 있으면 `dungeon.c`, `mklev.c`, `quest.c` 등의 소스를 훨씬
쉽게 이해할 수 있습니다.
